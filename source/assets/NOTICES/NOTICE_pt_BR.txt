3. APIs Nativas do Windows e Microsoft Windows SDK
Uso no projeto:
- Leitura e inspeção de descritores de segurança NTFS (DACLs, SACLs, ACEs, SIDs);
- Resolução de grupos locais e grupos de domínio Active Directory;
- Auditoria do Gerenciador de Serviços do Windows (SCM) e detecção de Unquoted Paths;
- Enumeração de compartilhamentos de rede SMB locais;
- Hashing criptográfico de integridade para evidências e snapshots;
- Integração de temas com a área de trabalho do Windows (DWM Mica e Dark Mode).

Componentes e Bibliotecas Vinculadas:
- `advapi32.lib` (GetNamedSecurityInfoW, SetNamedSecurityInfoW, GetInheritanceSourceW, etc.);
- `authz.lib` (AuthzInitializeResourceManager, AuthzInitializeContextFromSid, AuthzAccessCheck);
- `netapi32.lib` (NetShareEnum nível 502, NetApiBufferFree);
- `dwmapi.lib` (DwmSetWindowAttribute para Dark Mode e suporte a efeitos de janela moderna);
- `bcrypt.lib` (Microsoft Cryptography API: Next Generation - CNG, para geração de hashes SHA-256 de snapshots);
- `psapi.lib`, `shlwapi.lib`, `user32.lib`, `shell32.lib`.

Observação de Licenciamento:
- Estes componentes fazem parte integrante do sistema operacional Microsoft Windows e do Microsoft Windows SDK;
- Eles são utilizados por meio das APIs padrão do sistema operacional e não são redistribuídos por este projeto como bibliotecas open source avulsas.
