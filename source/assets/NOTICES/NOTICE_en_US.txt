3. Native Windows APIs and Microsoft Windows SDK
Usage in the project:
- Inspection and traversal of NTFS security descriptors (DACLs, SACLs, ACEs, SIDs);
- Resolution of local accounts and Active Directory domain groups;
- Windows Service Control Manager (SCM) auditing and detection of unquoted service paths;
- Enumeration of local SMB network shares;
- Cryptographic integrity hashing for audit evidence and snapshots;
- Desktop theme integration (Windows 11 DWM Mica and Dark Mode synchronization).

Linked Components and Libraries:
- `advapi32.lib` (GetNamedSecurityInfoW, SetNamedSecurityInfoW, GetInheritanceSourceW, etc.);
- `authz.lib` (AuthzInitializeResourceManager, AuthzInitializeContextFromSid, AuthzAccessCheck);
- `netapi32.lib` (NetShareEnum level 502, NetApiBufferFree);
- `dwmapi.lib` (DwmSetWindowAttribute for Dark Mode and modern window framing);
- `bcrypt.lib` (Microsoft Cryptography API: Next Generation - CNG, for SHA-256 evidence hashing);
- `psapi.lib`, `shlwapi.lib`, `user32.lib`, `shell32.lib`.

Licensing Note:
- These components are integral parts of the Microsoft Windows operating system and Microsoft Windows SDK;
- They are invoked via standard operating system platform APIs and are not redistributed by this project as separate open-source libraries.
