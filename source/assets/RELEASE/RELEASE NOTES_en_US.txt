RELEASE NOTES: Version 2026.10.17.0 — ACL AUDITOR
Release Date: October 17, 2026

General Summary of the Official Release:
This release marks the official launch of ACL Auditor — Visual NTFS Permissions and Compliance Analyzer for Windows. Built natively in modern C++20 and Qt 6.11.1, the application is engineered to empower system administrators, infrastructure consultancies, and cybersecurity teams to audit, visually explain, document, and remediate access control vulnerabilities within the NTFS filesystem.

Key Highlights and Features:

1. Visual Causal Effective Access Explainer
- Direct visual answer to the question: "Why can this user read, modify, or execute this file?".
- Hierarchical tree mapping identity resolution: User -> Direct Groups -> Nested / Universal Groups (Everyone, Authenticated Users) -> Inheritance Root Origin Folder -> Granted/Denied Rule.
- Verdict scorecard displaying Read, Write, and Execute badges, clearly highlighting whether access originates from protected inheritance or local explicit rules.

2. Automated NTFS Vulnerability & Risk Scanner
- Instant discovery of directories writable by regular unprivileged users (World-Writable via Everyone, Users, Authenticated Users).
- Automated detection of potential Binary Planting / DLL Hijacking vectors (.exe, .dll, .bat, .cmd, .ps1, .vbs residing in user-writable paths).
- Detection of excessive administrative privileges (WRITE_DAC and WRITE_OWNER) assigned to non-admin accounts.
- Identification of orphaned SIDs and unresolved legacy accounts from deleted domains or users.
- Weighted risk scoring (0 to 100) with intuitive severity categorization (Critical, High, Medium, Low).

3. Windows Services & SMB Shares Auditor
- Dedicated module to inspect the Windows Service Control Manager (SCM), uncovering Unquoted Service Paths containing spaces and verifying if SYSTEM service executables possess insecure write permissions.
- Local SMB network share auditing via NetShareEnum (level 502), correlating share-level DACL permissions with the underlying physical NTFS DACL to pinpoint misconfigurations.

4. Temporal Security Snapshot Comparison (Local SQLite)
- Capture comprehensive permission snapshots stamped with SHA-256 cryptographic hashes generated via Windows CNG (BCrypt).
- 100% offline persistence stored in a local SQLite database in %LOCALAPPDATA%/ACLAuditor.
- High-efficiency temporal diff engine to compare snapshots across dates (e.g., Monday baseline vs. current state), highlighting new files, deleted files, modified permissions, and newly added administrative rights.

5. Safe Read-Only Mode & Remediation Plans with Rollback
- Non-destructive philosophy: the application operates in read-only mode by default without executing unintended modifications on the disk.
- Integrated remediation planner generating ready-to-run PowerShell (.ps1) and Batch / icacls (.bat) scripts, complete with automatic preliminary backups (/save) and guaranteed rollback routines.

6. Executive Reporting for Consultancies
- Professional A4 PDF export with executive summary, metric tables, and risk scores designed for client presentations.
- Standalone interactive HTML report with responsive CSS styling and dynamic filters.
- Raw and structured data export in CSV and JSON formats.

7. Windows Explorer Integration & Localization
- Optional shell context menu integration: "Audit NTFS Permissions with ACL Auditor" in HKCU.
- Dynamic runtime translation between English (United States - en_US) and Português (Brasil - pt_BR).
- Native Windows 11 DWM title bar styling (Mica effect and Dark Mode).
